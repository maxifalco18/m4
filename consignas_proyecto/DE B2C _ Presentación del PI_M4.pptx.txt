Proyecto Integrador
Diseño e implementación de un pipeline de datos ETLT escalable sobre un Data Lake en la nube
Te desempeñas como Ingeniero de Datos en una organización que está migrando hacia una arquitectura moderna basada en la nube para gestionar grandes volúmenes de datos en crecimiento constante.

La empresa necesita una solución escalable que le permita integrar información proveniente de diversas fuentes, con el fin de mejorar la toma de decisiones basada en datos confiables y actualizados.

¿El desafío?
Tu tarea consistirá en diseñar e implementar un pipeline de tipo ETLT sobre una arquitectura de Data Lake, utilizando almacenamiento en la nube y formatos de archivo eficientes. 
Serás responsable de integrar datos con herramientas como Airbyte, procesarlos de forma distribuida mediante Apache Spark, y orquestar el flujo completo con Apache Airflow. 
Además, deberás automatizar algunas tareas clave del pipeline con GitHub Actions, aplicar buenas prácticas de seguridad en la nube y optimizar el rendimiento y los costos asociados al procesamiento y almacenamiento de datos.

Objetivos del PI
Desarrollar un pipeline de datos end-to-end sobre un Data Lake en la nube, que integre datos de diferentes fuentes, aplicando principios de arquitectura moderna, escalabilidad, seguridad y optimización de costos: 
Configurar y desplegar un pipeline de ingesta batch desde una fuente relacional o API REST hacia un almacenamiento tipo blob, usando Airbyte, validando la integridad de los datos mediante logs y conteos de registros
Diseñar y ejecutar jobs de Spark en PySpark para transformar los datos de la capa raw a la capa processed, aplicando joins, agregaciones y particionamiento y escribiendo el resultado en formato Parquet o Delta Lake

Objetivos del PI
Desplegar un DAG en Apache Airflow que coordine tareas del pipeline (ingesta, transformación y validación), incluyendo control de dependencias, reintentos y logs, ejecutable de forma agendada o manual.
Elaborar una presentación y un documento técnico de 4-6 páginas, que describa la arquitectura, decisiones de diseño, resultados del pipeline y de respuestas a las preguntas de negocio.
